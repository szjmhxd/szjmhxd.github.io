Ubuntu 22.04 GNOME 改英文环境 + 中文目录重命名指南

发表于2026-10-20|更新于2026-10-22|LinuxUbuntu
|浏览量:

适用：Ubuntu 22.04（jammy）桌面版（GNOME），系统装的是中文 locale，想把界面/终端改英文，并把 公共的/模板/视频/图片/文档/下载/音乐/桌面 等 XDG 目录改成英文名。
实例机器：szjm-ubu22，最终结果：界面英式英语（en_GB），目录全部英文名。

0. 核心结论（先看这个）

GNOME 桌面会话的语言不是由 LANG 单独决定的，优先级从高到低：

优先级 设置来源 作用
1（最高） /var/lib/AccountsService/users/<用户名> 里的 Language= GNOME 登录时读取，决定界面语言（en_US / en_GB）
2 ~/.config/locale.conf 用户级 locale，桌面会话下会被 1 覆盖
3 /etc/locale.conf（即 /etc/default/locale，localectl set-locale 写这里） 系统级，管 tty / SSH / GDM
  • LANGUAGE 决定界面用哪门语言，LANG 主要管字符集、排序、日期格式。只改 LANG 界面不会变英文。
  • 改完任何一项都必须”注销 → 重新登录”才生效。终端里重开窗口、锁屏都不算——环境变量是登录那一刻注入的，旧 shell 永远显示旧值。
  • 目录重命名和语言是两件事，但 GNOME 有个联动机制：登录时检测到语言变了，会弹「将标准文件夹更新到当前语言吗」。推荐顺序：先改语言 → 注销重登 → 在弹窗上点”更新名称”，一步到位。

1. 安装英文语言包

2. 改系统级 locale（管 tty/SSH/GDM）

  • LANGUAGE=en_US:zh_CN：优先英文，缺翻译时回退中文（避免生僻程序出 msgid 原文）。
  • 想纯英文（缺翻译时显示英文原文）：LANGUAGE=en_US，或不写回退。

3. 改 GNOME 界面语言（关键一步，二选一）

方式 A：GUI（推荐，最不容易错）

Settings → Region → Language → English (United States) 或 (United Kingdom)

GNOME 会自动写 AccountsService、同步相关设置。

方式 B：命令行

注：en_US = 美式，en_GB = 英式（拼写 Favourite、日期 dd/mm/yyyy）。两者都是英文，按喜好选。

4. 注销重登，处理目录弹窗

Log Out（注销）→ 重新登录（不是锁屏）。

登录后 GNOME 可能弹出：「将标准文件夹更新到当前语言吗？」

  • ✅ 点 「更新名称(U)」 —— 它会把 文档→Documents、下载→Downloads 等自动改名并更新配置。
  • 可勾选”不要再次询问我”。
  • ⚠️ 注意弹窗里箭头方向：左边是当前名、右边是新名，确认是”中→英”再点。

5. （可选/兜底）手动改目录

弹窗没出现，或想手动控制时：

⚠️ 踩坑记录（本次实操真实翻车点）：不要用 rmdir 目录 || mv 目录 新名 这种写法。空目录 rmdir 成功后 || 短路，mv 不执行 → 英文目录不存在 → xdg-user-dirs-update 报 “was removed, reassigning XXX to homedir”，把 8 个 XDG 项全部重置指向 ~，桌面图标会铺满整个 home。正确做法：先 mkdir 英文目录，再迁移内容，最后删空壳（即上面 5.1→5.3 的顺序）。

6. 验证

界面语言直接看：Settings / 文件管理器 / 右键菜单应为英文。

7. 遗留注意事项

  1. 应用内旧路径不自动更新：Firefox 下载目录、Thunderbird 附件路径等若记着旧的”下载”，需去应用设置里改成 ~/Downloads。
  2. 桌面图标显示名：Ubuntu 22.04 的 Desktop Icons NG 扩展按当前语言翻译标签，语言改对后标签自动变 “Desktop” 等。
  3. ~/.config/locale.conf：桌面会话下它被 AccountsService 覆盖，留着无害（SSH/tty 会话可用）；如果和 GUI 设置冲突造成困惑，可删除，一切以 Settings → Region 为准。
  4. 只想终端英文、GUI 保持中文：在 ~/.bashrc 末尾加 export LANG=en_US.UTF-8 LANGUAGE=en_US，注销都不需要，新开终端即生效。
  5. 改语言后个别程序乱码/方框：说明该程序字体或语言包不全，LANGUAGE 带回退（en_US:zh_CN）可缓解。

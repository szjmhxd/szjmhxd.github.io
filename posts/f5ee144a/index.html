Fail2Ban 规则字段详解

发表于2026-04-20|更新于2026-10-22|Linux
|浏览量:

一、全局 DEFAULT 字段说明

1. 封禁时间 bantime

IP 被封禁多久。常见值：10m（10 分钟）、1h、24h、7d、365d。

2. 统计时间窗口 findtime

在这个时间范围内统计失败次数。例如「24 小时内失败 3 次 → 封禁」。

3. 最大失败次数 maxretry

触发封禁的失败次数。

4. 封禁方式 banaction（关键）

封禁这个 IP 的所有端口。对比：

值 作用
iptables-multiport 只封指定端口
iptables-allports 全端口封禁

5. 执行动作模板 action

使用默认封禁动作（写 iptables 规则）。常见变体：

值 说明
action_mw 发邮件 + whois
action_mwl 邮件 + whois + 日志
action_ 仅封禁

6. 递增封禁（核心强化）

多次被封 → 时间越来越长。

每次封禁时间 ×2。例如：1 次 24h、2 次 48h、3 次 96h。

最大封禁时间上限。

7. 数据库保留时间 dbpurgeage

Fail2Ban 记录保留多久（用于递增封禁判断）。

二、sshd 专用规则字段

1. 是否启用 enabled

2. SSH 端口 port

等价于 ssh = 22。如果你把 SSH 改成 2222，这里要同步改。

3. 过滤规则 filter

使用 SSH 登录失败规则，检测：密码错误、用户不存在、认证失败。

4. 日志路径 logpath

常见系统路径：

系统 路径
Ubuntu / Debian /var/log/auth.log
CentOS /var/log/secure

5. 白名单 IP ignoreip

永不封禁这些 IP。建议扩展：你的办公 IP / 家里 IP / VPN 出口 IP。

6. 覆盖 DEFAULT 参数

sshd 段可以单独覆盖全局规则。
